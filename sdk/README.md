# `@awoscan/awo-suite-sdk` (`v2.2.0`)

Universal Cross-CMS Embed SDK and `<awo-suite-widget>` Web Component for all **23 AWO Suite B2B Corporate Tools** (`TR` / `EN`) by [AwoScan](https://awoscan.com).

- **Live Ecosystem Hub (TR / EN):** https://awosuite.awoscan.com/ · https://awosuite.awoscan.com/en.html
- **VIP Download Center (55+ Packages):** https://awosuite.awoscan.com/welcome · https://awosuite.awoscan.com/welcome-en

## Quick Usage (HTML Web Component)

```html
<script src="https://awosign.awoscan.com/sdk/awo-embed.js" defer></script>
<awo-suite-widget tool="awosign" lang="en" height="780px"></awo-suite-widget>
```
