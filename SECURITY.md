# Security Policy / Güvenlik Politikası

## Reporting a vulnerability
Please **do not** open a public GitHub issue for security problems.
Email **hello@awoscan.com** with the subject `SECURITY: AWO Suite` and include:
- affected tool / URL (e.g. `https://awosign.awoscan.com/app/`) or file,
- steps to reproduce,
- impact.

We aim to acknowledge reports within **3 business days**.

## Güvenlik açığı bildirimi
Güvenlik sorunları için lütfen herkese açık issue **açmayın**.
**hello@awoscan.com** adresine `SECURITY: AWO Suite` konusuyla; etkilenen araç/adres, yeniden üretme adımları ve etkisini yazarak bildirin. Bildirimlere **3 iş günü** içinde dönüş yapmayı hedefliyoruz.
