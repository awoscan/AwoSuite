# Changelog

## 2.2.0 — 2026-11-12
- 23 bilingual (TR / EN) tools live on `*.awoscan.com` (web studio + offline desktop PWA).
- AwoSign browser extension published on **Chrome Web Store** and **Firefox Add-ons**.
- AwoSign & AwoQuote published on **WordPress.org**; AwoSign Corporate Identity on **Odoo Apps Store** (16.0 / 17.0 / 18.0).
- New tools: **AwoOutdoor Media** and **AwoProof**; AwoMutabakat renamed to **AwoBalance**.
- `@awoscan/awo-suite-sdk` embed SDK with `<awo-suite-widget>` web component.
- Public discovery endpoints: `/openapi.json`, `/api/catalog`, `/.well-known/mcp.json`.
